# Using the public migration atlases

These maps open with prepared visualization models. Choose an atlas, move along its timeline, and use its filters and model choices where available. Dots represent the population unit displayed by that atlas.

## Sources and reconstruction methods

Open **Atlases & sources → Sources & methodology** in the map header. Each atlas has a public bibliography, an explanation of its population estimates and geography, and notes on its reconstruction choices. The [project repository](https://github.com/Khayoon/human-migration-atlases) links all seven maps and their documentation.

Source IDs and references in the prepared models connect individual records with the documented evidence. A reference does not mean that it supplies an exact reconstructed path, date or population estimate. Keep reported evidence separate from visualization assumptions.

The public site contains the prepared runtime data needed by the maps. Original supplied research documents and private raw research payloads are retained privately; they are not bundled with this public edition. The source and methodology documents explain the public evidence and limitations.

## Optional local imports

The app's Data tab supports native atlas JSON. See [DATA_FORMAT.md](DATA_FORMAT.md) for its format and the explicitly fictional starter examples. Browser edits are local to that browser; exporting a project saves a separate file. An import does not change this hosted edition or publish your file.

When preparing a new model, preserve source IDs, native names and chronology. Store population estimates and reconstructed geography separately from the original evidence. Label reconstructed paths, timing and demographic assumptions honestly. A population aggregate must not be copied into every branch or destination.
